# Roadmap moved

The roadmap is now split across [`docs/roadmap/`](roadmap/README.md):

- [`README.md`](roadmap/README.md): current status, standing rules, environments, and acceptance rules.
- [`batching.md`](roadmap/batching.md): Increments 0-7.
- [`excited_states.md`](roadmap/excited_states.md): the E1-E6 plan and Increments 8-11B. New excited-state results go here.
- [`future.md`](roadmap/future.md): later capabilities and their decided order.

History from before the split is under this path, because `git log --follow` can't trace a split:
`git log -- docs/development_batching_roadmap.md`.
